# Blessy Tuscano — Creative Portfolio

A bespoke, responsive portfolio website for **Blessy Tuscano** — Art Director, Designer & Visual Merchandiser. Built with React, Vite, Tailwind CSS, and custom styling.

## 🚀 Features

- **Project Archives:** Interactive project folders with live preview cards, hover thumbnails, and dedicated case study galleries.
- **Dynamic Age Calculation:** Automatically calculates Blessy's age dynamically based on her birth date (December 3rd, 2005) without requiring code updates.
- **Dual Theme Support:** High-contrast Dark mode (Cobalt Blue `#000be0`) & Light mode (Clean White `#fafafa`) with zero-transition contrast lag.
- **Collage View:** Dynamic responsive layout calculation ensuring clear legibility and zero overlap across mobile and ultra-wide screens.
- **Interactive Socials:** Quick-dial phone links (`tel:`), instant email (`mailto:`), clickable Instagram handle, and downloadable vCard (`.vcf`) for 1-tap contact saving.
- **Smooth Navigation:** Seamless marquee ticker, responsive mobile drawer navigation, and clean native page scrolling.

## 🛠️ Tech Stack

- **Framework:** React 18
- **Bundler:** Vite
- **Styling:** Tailwind CSS + PostCSS
- **Routing:** React Router v6
- **Icons:** Lucide React

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/Ad-debug-eng/blessy-tuscano.git
cd blessy-tuscano

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
